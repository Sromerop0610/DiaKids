# Módulo Frontend (`/client`)

En esta carpeta se desarrollará la interfaz web cliente de la aplicación utilizando **React**.

## Contenido y estructura futura
* **Componentes e Interfaz:** Pantallas y vistas interactivas adaptadas para niños y padres.
* **Lógica de navegación:** Control de rutas y gestión del estado en el cliente.
* **Integración API:** Servicios HTTP para conectar el frontend con el servidor.
* **Recursos:** Estilos CSS, imágenes y recursos multimedia de la aplicación.
