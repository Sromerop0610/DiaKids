# ProyectoOptativa

## Nombre del estudio

- Equipo JASD

## Problema

- El problema principal es que las aplicaciones actuales para el control de la diabetes infantil son complejas y poco accesibles, lo que genera una carga constante para los padres y no permite a los niños participar en el seguimiento de su enfermedad. Puedes consultar el [análisis detallado del problema de accesibilidad](https://github.com/Sromerop0610/ProyectoOptativa/blob/main/docs/propuesta/01-problema.md) para más información.
