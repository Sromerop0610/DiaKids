# Módulo Backend (`/server`)

En esta carpeta se desarrollará el servidor, la lógica de negocio y la API REST utilizando **Node.js**, **Express** y **MongoDB**.

## Contenido y estructura futura
* **API REST:** Rutas y controladores para recibir y enviar la información de los usuarios.
* **Base de datos:** Modelos de datos y esquemas en MongoDB (usuarios, registros de glucosa, etc.).
* **Seguridad y Lógica:** Autenticación de usuarios, validaciones y tratamiento de los datos.
* **Configuración:** Variables de entorno y ajustes del servidor.
